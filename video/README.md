## עריכה ורינדור מחדש

הסרטון אינו "קובץ וידאו שנערך" אלא **טיימליין קוד**: `src/film.html` מגדיר סצנות
(`sc(משך, HTML)`) וטראק כתוביות (`CUES`), ופונקציית `seek(t)` מציירת את הפריים המדויק
בזמן `t`. כל שינוי טקסט, תזמון או עיצוב נעשה בקובץ הזה, והרינדור דטרמיניסטי לחלוטין.

```bash
npm i playwright-core
node src/render.js frames                 # מייצר frames/*.jpg
python3 src/score.py                      # מייצר score.wav
ffmpeg -framerate 25 -i frames/f%06d.jpg -i score.wav \
  -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p \
  -c:a aac -b:a 160k -shortest lo-haya-tzava.mp4
```

הפונטים הנדרשים: Heebo, IBM Plex Mono, IBM Plex Serif (Google Fonts) — מותקנים במערכת
לפני הרינדור.
