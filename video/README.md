# סרטון הסבר: עדכון התקציב, עיריית חריש

סרטון טיפוגרפי אנכי לאינסטגרם ריעלס, בנוי מתוך שפת הקמפיין הקיימת.

## הקובץ המוכן

`out/harish-budget-reels-1080x1920.mp4`

| | |
|---|---|
| רזולוציה | 1080×1920 (9:16) |
| קצב פריימים | 30fps |
| קידוד | H.264 High, CRF 18, yuv420p, faststart |
| אודיו | רצועה שקטה (כדי שהקובץ ינוגן תקין בכל הפלטפורמות) |
| אורך | 87.2 שניות |
| קריאות ללא סאונד | מלאה. כל התוכן על המסך כטקסט |

## אזורי בטיחות

כל טקסט, מספר ותמונה קריטיים נמצאים בתוך:

* אופקית: 110px עד 970px (הכיתוב מיושר לימין עד 880px, קו הזהב ב 912px)
* אנכית: 300px עד 1500px

זה משאיר פנוי את הפס העליון, את טור הכפתורים בצד ימין ואת אזור הכיתוב,
הפרופיל והאודיו בתחתית של אינסטגרם.

## סולם טיפוגרפי

יש סולם אחד לכל הסרטון. אף מסך לא מגדיר לעצמו גודל, הכל נלקח מ `TYPE`
בתוך `video.html`:

| תפקיד | גודל | משקל | שימוש |
|---|---|---|---|
| hero | 104 | 800 | המספר המרכזי, פעם אחת בסרטון |
| fig | 88 | 800 | מספרי הנדסה, תברואה, גבייה |
| head | 64 | 800 | כל משפט וכל כותרת |
| sub | 58 | 700 | פסקאות באזור השמנת, בכחול עמוק `#12456e` |
| kicker | 48 | 600 | שורת פתיחה בזהב וכותרות המחלקות |
| caption | 44 | 500 | שורת ההסבר מתחת למספר |

השורות בקובץ `script.js` שבורות ביד כך שאף שורה לא צריכה להתכווץ כדי
להיכנס לרוחב. זה מה ששומר על גודל זהה מתחילת הסרטון ועד סופו.
בדיקה: `node check.js` מדפיס את הגדלים בפועל לכל מסך ומתריע אם
משהו הוקטן אוטומטית. הכלל: אסור לחרוג מ 22 תווים בשורת משפט ומ 28 תווים בשורת פסקה.

## שפה ויזואלית

הפלטה נדגמה ישירות מקבצי הרפרנס של הקמפיין:

| | |
|---|---|
| נייבי עמוק | `#0b2b44` |
| נייבי ביניים | `#123d60` |
| כחול בהיר | `#1a6ba4` |
| שמנת | `#fbfaf6` |
| זהב | `#f5b04a` |

* גרדיאנט נייבי אלכסוני, בהיר בפינה השמאלית תחתונה, כהה בימנית עליונה
* חלוקת מסך נייבי מעל, שמנת מתחת, כולל הטריז הכחול האלכסוני בתחתית
* קו זהב אנכי דק כאלמנט ההדגשה היחיד
* טיפוגרפיה: Heebo, משקלים 500 עד 800, יישור לימין בנייבי, מרכוז בשמנת
* בלי אייקונים, בלי גרפים, בלי חצים, בלי אדום וירוק, בלי תמונות סטוק

תנועה: הופעת שורות מדורגת עם עלייה קלה, מתיחת קו הזהב, מעבר מרוכך של
פאנל השמנת בין סצנות, וסחיפה איטית מאוד של הרקע. אין אפקטים נוספים.

## מבנה

20 מסכים, רעיון אחד לכל מסך, לפי הסדר בבריף: פתיחה, הכיוון בתקציב,
הנדסה, תברואה, גבייה, המספר המרכזי, מה זה עובד עירייה, הצמיחה של חריש,
המשמעות הניהולית, המסקנה, מסך האחריות עם ארבעת השמות, ומסך הסיום.

## עריכה והפקה מחדש

```bash
export NODE_PATH=/opt/node22/lib/node_modules
node render.js sheet    # פריים אחד לכל סצנה, ל out/sheet
node render.js frames   # רינדור מלא ל MP4
```

* `script.js` מכיל את כל הקופי, סדר המסכים ומשך כל מסך בשניות.
  שינוי טקסט או תזמון נעשה רק שם.
* `video.html` מכיל את מערכת העיצוב ואת מנוע התזמון. הפונקציה
  `setTime(t)` דטרמיניסטית, ולכן כל רינדור חוזר זהה לקודמו.
* `fonts/` הפונט, `assets/` ארבע התמונות העגולות שנחתכו מקובץ הקמפיין.

## שפה

הנוסח פושט לשפה שכל תושב קולט במעבר אחד: משפטים קצרים, בלי מונחים
מנהליים. למשל "לגורמים מבחוץ" במקום "חיצוניים", "כשהאשפה לא מפונה"
במקום "כשפינוי לא מתבצע", "הידע נשאר בעירייה" במקום "נשאר בתוך
המערכת". הטיעון והמספרים לא השתנו.

רשימות התחומים ומקבלי השירות נכתבות כפסקה זורמת, שתי אמירות בשורה,
ולא כרשימה אנכית של פריט בשורה. הצבע שלהן כחול עמוק ולא נייבי כמעט
שחור, כדי שיהיה ברור שזו פסקת המשך ולא כותרת.

## הערה על האורך

הבריף ביקש 60 עד 70 שניות. הטקסט המלא, בקצב קריאה נוח בנייד, יוצא
87 שניות. אפשר לקצר על ידי הורדת ערכי `dur` ב `script.js`, או על ידי
הורדת מסכים. שלושת המסכים שהכי קל לוותר עליהם בלי לפגוע בטיעון הם
`eng-why2`, `san-when` ו `shrink`, וביחד הם 11.2 שניות.
